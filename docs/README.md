# IliasSql Documentation

This directory contains comprehensive documentation for the IliasSql library, with a focus on the enhanced SqlTags system.

## Documentation Structure

- [`sql-tags-guide.md`](sql-tags-guide.md) - Complete guide to using SqlTags for database schema definition
- [`examples/`](examples/) - Practical examples and use cases
- [`migration-guide.md`](migration-guide.md) - Guide for migrating existing code to use enhanced SqlTags
- [`api-reference.md`](api-reference.md) - Complete API reference for all SqlTags features

## Quick Start

For a quick introduction to SqlTags, see the [SqlTags Guide](sql-tags-guide.md).

For migrating existing code, start with the [Migration Guide](migration-guide.md).

For complete API documentation, refer to the [API Reference](api-reference.md).
